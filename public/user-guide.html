Getting Started

Burrito is in private preview. You need an invite code to enter, and a passphrase to protect everything inside.

Enter your invite code

When you first open the app, you'll be asked for an invite code. Codes follow the format BURRITO-XXXX-XX. Enter yours and press Continue.

Create your passphrase

First launch

You'll be prompted to "Create your passphrase". Choose at least 8 characters. This passphrase derives the encryption key that locks your contributions and wraps to this device.

⚠️

Write it down. If you forget your passphrase, your data is unrecoverable. The server never sees your passphrase or your data. There is no reset.

Returning users

On every subsequent visit you'll see "Welcome back" — enter your passphrase to unlock the vault and return to the dashboard. If you need to start over on this device, tap Forget this device.

First-time dashboard

On your first login you'll see the FIRST LAUNCH panel. You have two choices:

  1. Try with demo data — loads 134 mocked contributions spanning the full year. Great for exploring the wrap experience before adding your own work.

  2. Start fresh — blank slate. Start adding contributions immediately via manual entry, file import, or a connected provider.

The Dashboard

The dashboard has three tabs: Dashboard Wraps Settings.

Dashboard tab

Your contributions live here, surfaced in three visual layers:

📅

Week-by-week cards for the past twelve months. Each card shows the signal text, source kind, category badge, and weight (1–5 dots). Tap LOAD MORE WEEKS to scroll further back.

📊
Year Rhythm

A 12-bar monthly histogram. The peak month glows hot red. High-activity months are purple. Baseline months are ink black.

🗂️
By Category

Horizontal bar chart breaking down your contributions across Delivery, Collaboration, Mentorship, Process, and Leadership.

🌯
Ready Enough

When you have enough signal, the WRAP IT 🌯 card appears. One click opens the wrap generation modal.

Wraps tab

Every wrap you've generated is listed here as a card. Each card shows the mode badge (YEAR-END or SNAPSHOT), the date range it covered, and a view wrap → link. From here you can also tap + Generate wrap 🌯 to start a new one.

03

Adding Contributions

Contributions are the signals the AI reads when generating your wrap. You can get them into the app three ways.

Manual entry

Tap the + Manual button in the dashboard toolbar to open "Add the work that systems miss."

  1. Write a short Contribution description — a sentence or two is enough.

  2. Set the Date (defaults to today).

  3. Choose a Category using the quick-select badges, or pick from the dropdown.

  4. Tap Add Contribution. The AI classifies it in the background. The modal stays open so you can add more.

🔐

Classified on save. Stored only on this device.

Available categories

Delivery Collaboration Mentorship Process Leadership

Not sure which to pick? Leave it — the classifier will choose when it processes your contribution.

File import

Tap the 📄 Import button to batch-import from a document. This is ideal for importing commit logs, sprint notes, or a personal brag doc.

Two-step import

  1. Label — give the batch a name (e.g., "Q1 commits").

  2. File — pick a .txt, .md, or .docx file (max 256 KB). Choose the AI model to use for extraction. Tap upload.

The file is parsed by the AI, which extracts individual contributions and queues them. A pending indicator appears in the timeline while processing runs.

Provider sync

Connect a provider in Settings to have contributions pulled automatically. Currently supported:

◈
GitLab Dedicated

Syncs MRs, code reviews, and commits. Authenticate with an API token. Shows last-sync time and a manual sync trigger.

⬡
More coming

GitHub, Jira, Slack, and Confluence integrations are in the pipeline. File import covers all of these in the meantime.

💡

Weight matters. Each contribution has a weight from 1–5, set by the classifier. High-weight contributions (4–5) appear in the Highlight Reel and Identity slides. If something important was under-weighted, add a manual entry with more descriptive signal text.

04

Generating a Wrap

When you're ready, tap Generate Wrap or WRAP IT 🌯. The modal is titled "Pick the lens for this story."

Choose a mode

Mode A
Snapshot
Stat-forward, personal check-in.
Pick any date range using the FROM and TO fields. Good for quarterly reviews, sprint retrospectives, or a mid-year check-in.
Mode B
Year-End
Editorial, appraisal-ready.
Automatically locked to the full calendar year. The AI writes longer, more editorial copy — suited for performance reviews and annual recaps.

Choose a model

Select from the MODEL dropdown. The available models depend on your deployment, but typically include:

  • claude-haiku-4-5 Fast and cost-efficient. Good for most wraps.
  • gpt-5.5-1 Azure Foundry. High quality for Year-End mode.

Generation timeline

  1. Tap Generate (bottom right, hot red).

  2. The modal shows "Generating your wrap… ~20 seconds." Ten slide prompts run in parallel on the server.

  3. If the service is busy, you'll see a "Queued" status with a View status → link.

  4. Once done, your wrap is encrypted and saved locally. The app navigates to the wrap viewer automatically.

🔐

Your contributions are sent to the AI proxy without identifiers — no user IDs, no names, no external IDs. The result comes back and is stored encrypted on this device.

05

Your Slides

Every wrap contains up to 10 slides. Each slide targets a specific dimension of your work, using only the contributions that are most relevant to it.

Wraps are displayed in two formats — Desktop (16:9, auto-advancing every 6 seconds) and Phone (vertical, swipe-friendly). Navigation arrows let you move forward and back at your own pace.

01
Launches Shipped

Major outcomes that crossed the finish line. Counts only high-weight delivery contributions.

02
Velocity

Throughput — how much you moved, and how consistently.

03
Cross-Team Impact

Reviews written, blockers cleared, teams helped. Collaboration and unblocking signal.

04
Deep Work Streak

Sustained focus periods — stretches of delivery and process without context switching.

05
Mentorship

Time invested in helping teammates grow. Draws from mentorship-tagged contributions.

06
Initiative

Self-started work: things nobody asked for that you shipped anyway.

07
Collaboration Style

How you work with others — async habits, communication patterns, documentation.

08
Consistency

Distribution of contributions across the year. No dead months, no crunch spikes.

09
Highlight Reel

Your three defining moments — the highest-weight contributions from across all categories.

10
Identity

The synthesis slide. The AI names your signature style based on your top five contributions.

💡

A slide won't appear if there isn't enough signal for it. A wrap with strong delivery contributions but no mentorship will simply skip the Mentorship slide. More contributions = more slides.

06

Settings & Providers

Open the Settings tab from the dashboard. The heading reads "connect your tools — we watch the work you've already done. nothing manual."

Your name

Enter your name in the YOUR NAME field and tap Save name. This personalises the dashboard greeting and is used in wrap copy. It is stored locally — the server never sees it.

Connecting providers

The provider grid shows every available integration. Unlinked providers show a + LINK badge. Connected providers show a ON badge alongside "● connected · X account(s)" and last-sync information.

To connect a provider

  1. Click the provider tile to open Add Provider.

  2. Enter your API token (for GitLab Dedicated, this is a personal access token).

  3. Save. The provider appears as connected with an initial sync queued.

Leaving the preview

The Leave preview section at the bottom of Settings lets you clear your invite session. You'll need a valid invite code to re-enter. This does not delete your encrypted data — it only ends the current authenticated session.

Privacy Model

Burrito is local-first by design. Here's exactly what stays on your device and what leaves it.

What never leaves your device

  • Your passphrase and encryption key — derived locally, never transmitted
  • Your name and profile information
  • Raw contribution text once classified and stored
  • Generated wrap content — encrypted with AES-GCM-256 in IndexedDB
  • External IDs, user IDs, and repository identifiers

What is sent to the server

  • Contribution signal text only (no identifiers) when classifying or generating a wrap
  • An anonymous per-install JWT — no name, no email, no account link
  • File contents during a file import (stripped of metadata before sending)

Encryption specifics

  • Algorithm: AES-GCM-256
  • Key derivation: PBKDF2-SHA-256, 600,000 iterations, 16-byte device salt
  • Key storage: Memory only — cleared on tab hide, 15-minute idle, and page unload
  • At rest: Each IndexedDB record stores { iv, ct } — opaque without the key
⚠️

Your browser's storage can be evicted under disk pressure. Enable persistent storage when prompted ("Allow this site to store data on your device") to guard against eviction. The app calls navigator.storage.persist() during unlock.
